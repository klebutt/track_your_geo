# Capability: Customer web report (AI Recommend site)

## Purpose

Static AI Recommend marketing site and private per-firm report pages at `/r/<slug>/` on Cloudflare Pages, built from `site/` and vault manifests without storing prospect lists in git.

## Requirements

### Requirement: Static site build

`site/build.py` MUST copy `site/public/` to `site/dist/`, inject `_redirects` for booking, build a fictional sample report by default, and optionally build vault batch pages when passed `--vault` and `--batch`.

#### Scenario: Default build includes sample

- **WHEN** build runs without `--no-sample`
- **THEN** `dist/sample-report.pdf` and `/r/sample/` exist using the riverside-accountants gold fixture only

#### Scenario: Vault batch pages

- **WHEN** build runs with `--vault` and a manifest of `status=ok` rows
- **THEN** each firm receives `/r/<slug>/index.html`, a byte-identical PDF copy, and `{batch}-links.csv` is written in the vault (not git)

### Requirement: Private report pages

Report URLs under `/r/*` MUST send `noindex, nofollow, noarchive` via `X-Robots-Tag` (Cloudflare `_headers`) and `<meta name="robots">` in `site/templates/report.html`. Report pages MUST use `Referrer-Policy: no-referrer` on `/r/*`.

#### Scenario: Slugs not in sitemap

- **WHEN** `robots.txt` is served
- **THEN** it does not list individual `/r/` slugs (privacy relies on headers and unguessable slugs)

### Requirement: Web report content parity with PDF

`/r/<slug>/` body HTML MUST be generated by `tygeo.customer_web_report.build_customer_report_body_html` so section order and copy mirror the customer PDF (hero X of N, who showed up, meaning, deeper insights, snapshot table, questions list). Sample banner callout MUST render when `_sample_banner` is present.

#### Scenario: Rebuild from sidecar JSON

- **WHEN** `{report}.run.json` exists beside exported markdown
- **THEN** site build prefers the JSON snapshot over markdown reconstruction

### Requirement: Markdown rendering on web pages

Customer report pages MUST render markdown constructs used in exports (headings, bold, links, lists, tables) as HTML, not raw markdown source.

#### Scenario: Loss lines with bold competitor names

- **WHEN** loss entries include `**Competitor**` markdown
- **THEN** the web page shows bold competitor names

### Requirement: Report view logging

Cloudflare Pages function `site/functions/r/[[path]].js` MUST insert a D1 row for each `/r/` request with timestamp, slug, path, country, user agent, and ASN when `DB` binding is configured, and MUST NOT store client IP addresses. Logging failures MUST NOT block page delivery.

#### Scenario: Serve when D1 unavailable

- **WHEN** the D1 binding is missing or insert fails
- **THEN** the static report page still loads

### Requirement: Booking redirect

The built site MUST include a `302` redirect from `/book` to the Google Calendar appointment URL from `site/config.py` / `tygeo.brand.BOOKING_LINK_RAW`.

#### Scenario: Short booking link in report template

- **WHEN** a report page renders the booking button
- **THEN** it links to `https://airecommend.co.uk/book` which redirects to Calendar

### Requirement: Report page actions

Each `/r/<slug>/` page MUST offer a primary "Book a 15-min call" action and a PDF download of the bundled report file, plus footer trading-name and privacy link consistent with the marketing site.

#### Scenario: PDF download matches manifest hash

- **WHEN** build verifies `sha256` from the manifest
- **THEN** mismatched PDF bytes fail the build for that firm
